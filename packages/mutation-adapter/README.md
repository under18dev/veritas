# @under18dev/veritas-mutation-adapter

Mutation testing adapter (@mizchi/mutator) for Veritas

Part of [Veritas](https://github.com/under18dev/veritas), specification-aware test verification for TypeScript/JavaScript projects. Most users install the main package, which provides the `veritas` and `veritas-mcp` commands and the Node API:

```bash
npm install -D @under18dev/veritas
```

This package is an internal building block of that package; its API may change between minor versions. Source: [`packages/mutation-adapter`](https://github.com/under18dev/veritas/tree/main/packages/mutation-adapter).
