# ADR 0008: npm package name

## Context

The unscoped name `veritas` is taken on npm. Packages currently use the placeholder scope `@veritas/*`, which is not owned by this project.

## Decision

Pending. A final name will be chosen before the first public release and applied everywhere (packages, docs, CLI help).

## Consequences

Documentation must not present `@veritas/*` as published packages until this ADR is accepted.
